# Foodie App

Foodie App is a simple React Native Expo app for discovering, saving, and managing favorite recipes. It includes a home feed, category filters, recipe details, and a custom recipe feature for adding, editing, and deleting your own recipes.

## Features

- 10+ recipe categories
- Category filtering
- Complete recipe details
- Favorite/unfavorite recipes
- Favorites screen
- My Food section
- Add custom recipes
- Image picker
- My Recipes
- Edit recipes
- Delete recipes
- Functional navigation/back button

## Run

```bash
npm install
npx expo start
```

This project is built using React Native and Expo.
